# CinemaLab

A small C# console application created for practice:

- Loops and program flow
- Switch statements
- User input validation
- String manipulation
- Methods and code structure

## Features

1. **Youth or Pensioner Pricing**
   - Calculates cinema ticket price based on age.

2. **Group Pricing**
   - Calculates total cost for a group based on each person's age.

3. **Repeat Input 10 Times**
   - Uses a `for` loop to repeat user input ten times.

4. **Third Word Finder**
   - Splits a sentence and returns the third word.
